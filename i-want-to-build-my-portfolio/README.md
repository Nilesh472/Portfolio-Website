# Nilesh Yadav Portfolio

Single-page premium portfolio site built as a static frontend for easy deployment.

## Files

- `index.html`: semantic page structure and SEO metadata
- `styles.css`: full visual system, responsive layout, and premium dark theme
- `data.js`: centralized content for easy updates
- `script.js`: rendering, navigation, counters, filters, reveal effects, and form behavior
- `assets/Nilesh-Yadav-Resume.pdf`: resume download asset
- `assets/nilesh-photo.jpeg`: profile image used in hero and about sections
- `vercel.json`: simple Vercel-friendly static hosting config

## Update points

- Replace social links in `data.js` if your final LinkedIn or GitHub URLs differ.
- Replace placeholder metrics, testimonials, and project case studies in `data.js`.
- Replace the placeholder LinkedIn URL in `data.js` with the real profile link.
- Update `og:url` in `index.html` before deployment.
- The contact form currently opens the user's email client. Connect it to a backend or form service if you want direct submissions.
